# p5 决策与政策中心（E 集成岗）

> 页面归属：E（集成岗）　|　数据源：`data/demo/policy.json` + `data/demo/tasks.json`（见 `data/CONTRACT.md`）
> 对应需求页：**08 政策与市场规则中心 + 09 决策任务中心**
> 核心：把"政策规则"与"AI 决策任务"串起来——政策影响分析 → 任务流转闭环，呼应"管得清"。

---

## 页面定位

p5 是经营闭环的**规则与任务枢纽**：
- **政策侧**：东北四省区政策 + 分类 + 动态 + 企业影响分析（可溯源）
- **任务侧**：AI 决策任务列表 + 状态流转（待分析→已执行→复盘），展示"AI建议→人工确认→执行"闭环

用 **Tab 切换**（政策 / 决策任务）减少首屏负担。

## 板块一 · 政策中心（`data/demo/policy.json`）

| 模块 | 内容 | 数据 |
|------|------|------|
| 1. 统计卡 | 政策总数 / 分类数 / 覆盖地区 / 已实施数 | `list` 聚合 |
| 2. 政策分类筛 | 按 `category` 分类（现货交易/绿证/绿电/辅助服务/新能源入市）| `list[].category` |
| 3. 政策列表 | 每条：标题 / 发布机构 / 文号 / 日期 / 地区 / 状态；点击展开"企业影响分析" | `list` |
| 4. 影响分析 | 展开后显示 `impact`（市场交易五星等）+ `key_change` + `credit`（溯源）| `list[].impact/key_change/credit` |
| 5. 溯源 | 每条政策显示 `agency/doc_no/link`（可溯源）| `list` |

## 板块二 · 决策任务中心（`data/demo/tasks.json`）

| 模块 | 内容 | 数据 |
|------|------|------|
| 1. 任务列表 | 8 条任务：类型 / 标题 / 负责人 / 状态 / 置信度 / 风险 | `tasks` |
| 2. 状态徽标 | 按 `status` 显示颜色（已确认=绿 / 待确认=黄 等）| `tasks[].status` |
| 3. 任务详情 | 展开显示 `decision_id / model / confidence / risk` | `tasks` |
| 4. 状态流转演示 | 点击按钮模拟流转（待分析→…→效果复盘），本地交互 | 前端交互 |

## 数据加载

```
await Data('demo/policy')   # 政策
await Data('demo/tasks')    # 任务
```

## 交互

- Tab 切换：政策 / 决策任务
- 政策：点击条目展开影响分析 + 溯源
- 任务：点击"推进状态"按钮，在状态链上流转（演示闭环）
