# p4 绿电入市决策中心（C 前端）

> 页面归属：C（前端）　|　对应需求页：**06 绿电入市决策中心 + 07 AI 经营情景实验室**
> 定位：**全产品核心模块**，新能源"交易决策工作台"——从市场行情 → 资源盘点 → 方案生成 → 三方案 PK → 收益风险权衡 → 决策解释 → 情景推演
> 数据：依赖 A 的 `market.json / generation.json / storage.json / tasks.json`；**当前 A 数据未合并，先用需求示例数字内联，数据到位后切 `Data('demo/xxx')`**（页面结构不变，只改数据源）

---

## 一、模块划分（8 模块 + 情景实验室）

### 1. 市场雷达
- 5 个市场卡片：中长期 / 日前 / 实时 / 绿电 / 绿证
- 每卡：市场名 + 核心数字（均价 元/MWh、波动率）+ 说明
- 示例值：中长期 332 元/MWh、日前 350 元/MWh（吉林现货锚点）、实时 214 元/MWh、绿电溢价 45 元/MWh、绿证 5.15 元/个

### 2. 企业资源池
- 资源池图形：明日预测发电 **142.3 MWh** / 中长期已锁定 **65 MWh** / 储能可调 **18.2 MWh** / 可灵活交易 **59 MWh**
- 直观呈现"明天能卖多少"的拆解

### 3. 方案生成器
- 风险偏好选择：保守 / 均衡 / 激进（三选一）
- 手动模式：拖动"中长期 ↔ 现货"比例滑条（默认 65% / 35%），储能套利开关
- 点击【生成策略】→ 联动更新三方案卡 + 收益-风险图

### 4. 三方案决策卡
- 方案 A 稳健型：预计收益 17.8 万、偏差风险低、收益波动低
- 方案 B 均衡型：预计收益 18.4 万、偏差风险中、收益波动中（**AI 推荐**，高亮）
- 方案 C 收益型：预计收益 19.2 万、偏差风险较高、收益波动高
- 对比项：预计收益 / 偏差风险 / 收益波动 / 新能源利用率

### 5. 收益—风险地图
- 散点图：X=风险、Y=收益，标注 A/B/C 三方案
- 显示推荐 B 是"收益/风险效率较优"，非单纯最高收益

### 6. 决策解释
- 为什么不是收益最高的 C：C 收益高 **4.8%**，但预测偏差暴露 **+21%**，储能剩余调节空间不足；风险调整后 B 更优

### 7. 市场规则影响
- 当前策略受吉林规则 A / 规则 B / 偏差考核条款 C 影响
- 按钮：【查看规则原文】【AI 解释规则】（规则原文来自 A 的 `market.json.rules`，先内联占位）

### 8. 情景实验室（需求页 07）
- 预置 8 场景：寒潮来袭 / 风速骤降 30% / 光伏出力降 25% / 现货价涨 30% / 储能容量降 20% / 并网限制增 / 预测偏差扩大 / 自定义
- 选场景 →【开始推演】→ 展示动态过程（环境→预测→储能→可交易→组合→收益→风险）
- 左：原始方案（发电 142 MWh / 现货 40% / 储能放电 18 MWh）
- 右：优化后方案（发电 118 MWh / 现货 27% / 储能重新调度）
- 底部：AI 应对措施四步（降现货敞口 / 提中长期锁定 / 晚峰释放储能 / 持续监测）

## 二、交互设计

| 交互 | 行为 |
|------|------|
| 方案生成器 | 选风险偏好 或 拖比例 → 点【生成策略】→ 三方案卡数值 + 收益-风险散点更新 |
| 三方案卡 | 可点击选中，高亮展示；AI 推荐 B 带"推荐"徽标 |
| 收益-风险图 | 散点 hover 显示方案名/收益/风险 |
| 情景实验室 | 选场景 → 推演 → 左右方案对比 + AI 应对四步展示 |
| 数据时间/可信标注 | 顶部显示数据更新 + "Level 1 模拟" 标注 |

## 三、技术要点

- 从 `template.html` 复制骨架；Vue 3 全局版 **Options API**（禁 setup()/import Vue/SFC）
- 图表走 `chart-view.js`：收益-风险用 **scatter 散点**（多序列），市场雷达用卡片不用图
- 计算/格式化走 A 计算层：`formatNumber` / `formatPercent` / `formatMoney`
- 数据：**先内联示例数字**；A 数据合并后切 `Data('demo/market')` / `Data('demo/generation')` / `Data('demo/storage')` / `Data('demo/tasks')`
- 可信 AI 卡片：B 的 `ai-card.js` 未建，**先做占位卡片**（结论/依据/置信度/模型），B 提供后替换
- 禁绝对路径；改 class 后本地重跑 Tailwind 编译（合并前 B 最终编译）
