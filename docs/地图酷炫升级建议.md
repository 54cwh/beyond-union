## 1. 已知边界问题（已修复：FL-02 终点夹到蒙东南缘赤峰 [118.88, 42.28]，并新增 geo-map.js 的 fitCoord 把区外坐标夹回底图边界）

`flows.json` 的 `FL-02`（蒙东外送华北）`toCoord: [116.4, 40.21]` 落在 `ne`（东北四省）底图之外，
`toCoord` 已改为蒙东赤峰边界点，且 `geo-map.js` 已内置 `fitCoord`（区外坐标自动夹回边界，保留外送指向感）。
ECharts `geo` 坐标系会把它画在可视区外，导致该飞线「断掉/消失」。

二选一：
- **方案 A（裁剪）**：`flowOption()` 里对 `resolveFlows` 结果过滤，`toCoord` 超出底图边界的流向隐藏，或终点吸附到最近省界点；
- **方案 B（区外锚点）**：给「华北」做一个固定区外节点——独立 `scatter` 画在 `[116.4, 40.21]`，飞线终点指向它，并把 `geo` 的 `center/zoom` 微调让它落在右下角可视处（或换更大范围底图）。

## 2. ECharts GL 3D 柱状图（最出效果，强推）

在地图质心立 3D 柱（装机容量 / 今日发电 / 收益），大屏感立现。

- 依赖：`assets/vendor/` 新增 `echarts-gl.min.js`（与 `echarts.min.js` 版本对齐，页面在 echarts 之后引入）
- 参考：https://echarts.apache.org/zh/feature.html （3D 柱 / 3D 地球）
- 骨架（在 `buildOption()` 增加 `layer === "bar3d"` 分支）：

```js
function bar3dOption() {
  const t = theme();
  const data = provinces.map((p) => ({
    name: p.name,
    value: [p.center[0], p.center[1], p[kpi]],
    meta: p,
  }));
  return {
    backgroundColor: t.background,
    tooltip: {
      trigger: "item",
      formatter: (params) =>
        tipTitle(params.data.meta.name) + "<br/>" + kpiLabel(kpi) + "：" + params.data.meta[kpi],
    },
    visualMap: { type: "continuous", min: /* 数据 min */, max: /* 数据 max */,
      inRange: { color: t.kpiRamp }, textStyle: { color: t.ink } },
    geo3D: {
      map: "ne", roam: true, boxHeight: 12, regionHeight: 1.5,
      itemStyle: { color: t.surface, borderColor: t.border },
    },
    series: [{
      type: "bar3D", coordinateSystem: "geo3D", data: data,
      shading: "lambert", bevelSize: 0.3,
      itemStyle: { color: t.typeColor.wind, opacity: 0.9 },
    }],
  };
}
```

## 3. 飞线增强（在现有 flowOption 上微调）

现有飞线已用 `effect.symbol: "arrow"`，可再加：

- **粗底细顶双层 lines**：底层半透明粗线 + 顶层细亮线 + 流动箭头，迁徙感更强；
- **`curveness` 按 `value` 动态**：功率越大弧度越大（数据里已带 `value`）；
- 端点已有 `effectScatter` 脉冲，可再加「流入侧呼吸圈」。

参考：https://github.com/yyhsong/iDataV （地图热点/飞线动效）、flowmap.gl

## 4. 粒子风场 / 流动背景（进阶，绿电氛围）
