《北域绿联——东北新能源入市与多能协同智能决策平台》产品概述产品定义北域绿联是面向东北地区新能源发电企业的新能源市场化经营智能决策平台，帮助企业完成“预测—优化—交易—决策—验证”的完整经营闭环，实现从“看能源”到“算经营”。问题陈述东北地区新能源装机快速增长，但企业在市场化交易中面临三大痛点。一是“发不准”：风电、光伏出力受天气影响波动剧烈，传统预测误差偏大，难以支撑交易决策。二是“算不清”：风光储多能协同与电力市场价格动态耦合，企业缺乏统一的收益—风险测算工具，决策多依赖经验。三是“证不实”：现有系统多为数据大屏，只展示结果、不解释依据，AI结论不可追溯，无法支撑经营问责。目标用户平台面向新能源场站的三类核心角色。角色一·企业决策层（CEO/总经理）：关注整体经营收益与风险，需要“今天经营如何、明天怎么办”的一屏决策视图。角色二·场站运营负责人：关注发电预测、储能调度与设备运行，需要可信的预测结果与可执行的运行方案。角色三·交易负责人：关注市场行情与交易组合，需要可解释的交易策略、风险提示与人工确认闭环。核心价值主张平台以六大核心能力支撑经营闭环：发得准（智能出力预测）、储得优（风光储协同优化）、卖得好（绿电交易辅助决策）、算得清（收益—风险—偏差统一测算）、管得清（政策—规则—数据统一管理）、证得实（真实运行结果持续验证）。核心用户故事作为企业决策层，我希望每天进入系统后一屏看到今日经营结果与明日经营预测，以便快速掌握经营态势并作出决策。作为场站运营负责人，我希望预测结果附带置信区间与影响因子解释，以便判断预测可信度并据此安排储能调度。作为交易负责人，我希望系统给出多方案比较与推荐理由而非单一结论，以便在风险与收益之间作出理性选择。作为交易负责人，我希望每条AI建议都附带数据来源、模型版本与置信度，以便追溯结论依据并对决策负责。作为企业决策层，我希望看到“基准方案—AI方案—实际结果”的三栏对比，
以便验证平台的实际价值。作为场站运营负责人，我希望数据缺失时系统能明确诊断“缺什么”，以便有针对性地补齐数据、逐步启用更多模块。成功指标主指标：AI辅助决策的采用率与偏差成本下降幅度，用以证明平台“算得清、卖得好”。护栏指标：预测误差（MAPE）、新能源利用率（弃电率）、储能循环寿命健康度，确保不以牺牲资产寿命换取短期收益。产品路线图第一阶段（MVP）：打通“预测—优化—交易”核心链路，覆盖单一场站的风光储优化与入市决策，建立可信AI机制与数据底座。第二阶段（增长）：扩展多场站、多省份的区域经营能力，强化情景实验室与政策—市场规则中心，形成决策任务闭环。第三阶段（规模化）：接入真实交易执行与结果回填，沉淀决策—结果数据库，以真实运行数据持续验证并优化模型。关键风险与缓解风险一：真实数据缺失导致演示与验证缺乏说服力。缓解：内置模拟演示数据与数据诊断机制，明确区分“模型模拟、历史回测、企业试用、真实生产验证”可信等级。风险二：AI结论不可信引发用户抵触。缓解：所有建议强制附带依据与置信度，坚持“AI辅助决策、不替代经营”。风险三：模型预测误差超预期。缓解：建立模型验证与效果复盘闭环，用“基准—AI—实际”三栏对比持续修正模型。范围外平台定位为经营决策工作台，不做大量无意义仪表盘、复杂SCADA控制界面，不做“AI自动控制风机”“AI自动报量报价”等替代人工经营的功能。一、产品设计思路产品核心逻辑：让新能源企业在平台里真正完成一次经营决策。平台构建了完整的业务闭环：数据接入 → 数据诊断 → 发电预测 → 风光储优化 → 入市方案生成 → 情景压力测试 → 人工确认决策 → 执行结果回填 → 收益与偏差复盘 → 模型持续优化。六大核心能力：【发得准】智能新能源出力预测【储得优】风光储协同优化【卖得好】绿电市场交易辅助决策【算得清】收益、风险、偏差统一测算【管得清】政策、市场规则、数据统一管理
【证得实】真实运行结果与优化效果持续验证二、产品设计原则原则1：产品定位为“经营决策工作台”，而非“数据大屏”。页面中不能只有发电量、SOC、电价、曲线等展示性数据，必须继续回答：发生了什么？为什么？会造成什么影响？有哪些方案？系统推荐哪个？预计多赚/少亏多少？依据是什么？原则2：每一个AI结论必须可以解释。例如，不能仅显示“AI建议：现货比例25%”，必须同时给出推荐方案（中长期75%＋现货25%）、推荐原因（① 明日14:00—18:00风功率预测下降、② 预测置信区间扩大、③ 当前储能SOC较高、④ 晚高峰价格预计上涨）、数据更新时间（15:40）、模型版本（MarketDecision-v1.2）与置信度（87%）。原则3：所有数据必须可以追溯。任何一个指标均允许点击【查看数据来源】，并显示数据名称、数据来源、更新时间、数据质量、原始数据、处理方法与模型版本。原则4：所有模型结果必须形成“方案比较”。不能只有“系统建议这样做”，必须提供方案A、方案B、方案C与AI推荐方案，并比较收益、风险、新能源利用率、偏差成本、储能循环与置信度。原则5：建立“前—中—后”效果闭环。决策前给出基准方案，决策中给出AI优化方案，执行后记录实际结果，最终得到基准收益、AI预计收益与实际收益三者的对比，以验证产品的实际价值。三、整体信息架构建议形成12个核心页面：01 项目中心、02 运营工作台、03 数字能源地图、04 发电预测中心、05 风光储优化中心、06 绿电入市决策中心、07 AI经营情景实验室、08 政策与市场规则中心、09 决策任务中心、10 经营成效与报告中心、11 案例与验证中心、12 数据可信中心。左侧菜单按三大板块组织：经营决策板块（运营工作台、发电预测、风光储优化、绿电入市、情景实验室）、经营管理板块（数字能源地图、决策任务、政策规则、经营报告）、可信支撑板块（数据中心、案例验证、项目管理）。右上角固定显示：当前企业、当前场站、数据状态、预警、AI助手与用户信息。四、贯穿所有页面的“北域AI副驾驶”平台内置【北域AI Copilot】，始终固定在各页面右侧。用户可以直接提问，例如：“明天为什么建议降低现货比例？”“如果下午风速下降20%，收益会怎样？”“为什么今天储能建议提前充电？”“吉林现在有哪些储能相关交易规则？”“给我生成明日经营计划。”AI回答必须调用当前项目的真实数据，并采用固定结构：结论 → 数据依据 → 原因 → 影响 → 建议 → 置信度 → 查看原始数据 → 立即进入相关模型。
