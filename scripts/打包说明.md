# 打包说明（北域绿联 → 单 EXE）

> 维护：E 集成岗（cwh）　|　**打包是最后一步**：开发 / 测试 / 验收全程走 web，中途不要打包
> 相关文件：`scripts/build_exe.sh` + `北域绿联.spec`

---

## 1. 开发与验收（打包前）

```bash
bash scripts/serve.sh            # 开发预览服务器（http://127.0.0.1:8000）
uv run python -m http.server 8000 # 或直接起 http server
```

- 访问 `http://127.0.0.1:8000/pages/p1.html` ~ `p6.html`
- **禁止双击 html 文件**（file:// 下 fetch 会被 CORS 拦截）
- 测试：`npm test`（JS 单测）+ `uv run pytest`（E2E + 契约）

## 2. 打包前检查清单

- [ ] 全量测试通过：`npm test` + `uv run pytest` + `uv run ruff check .`
- [ ] `tailwind.css` 已编译（改过 class 后跑 `bash scripts/build_tailwind.sh`）
- [ ] 数据文件齐全：`data/demo/*.json`（A 数据岗）
- [ ] 资源本地化：`assets/vendor/`（vue/echarts 本地文件）、`assets/fonts/`（Inter 字体）——**无任何 CDN 依赖**
- [ ] 无本机绝对路径残留（`grep -rn "/home/\|/mnt/\|D:" pages/ assets/ data/ scripts/ app.py` 应为空）

## 3. 打包

```bash
bash scripts/build_exe.sh        # → dist/北域绿联.exe（单文件）
```

- 使用 `北域绿联.spec`：`datas` 元组写法，Windows / Linux / Wine 通用
- 打包产物：`dist/北域绿联.exe`（console=False，无黑框）

## 4. 验收

| 项目 | 方式 |
|------|------|
| GUI 模式 | Windows 成员双击 EXE，验 pywebview 窗口 |
| 浏览器模式 | 命令行 `北域绿联.exe --web`（或 Wine 下验证）|
| 数据加载 | EXE 内 `/data/demo/*.json` 是否随包可读 |
| AI 副驾驶 | 右下角 AI 按钮 → 提问 → 回答（copilot.js + ai-qa.js）|
| 演示模式 | p1『开始演示』按钮 → 90-120s 演示链路 |

## 5. 常见问题

- **打包后数据 404**：确认 `data/` 在 spec 的 `datas` 里（已含）
- **字体缺失**：`assets/fonts/inter-*.woff2` 必须存在（common.css @font-face 引用）
- **CDN 请求失败**：全站禁止外链（tailwind 已本地化、vue/echarts 在 vendor/）
- **Wine 打包**：需 Wine + Windows Python + PyInstaller，路径用相对写法（spec 已兼容）
